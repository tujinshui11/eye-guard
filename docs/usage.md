# 护眼助手 · 日常使用指南

> 面向：自用（每天办公）。3 分钟读完，之后看图操作即可。
> v2 新增：7 档场景模式（含冷色）· 深海/暖橙/二次元三主题 · 时间调度 · 感光监测

## 一、第一次：让他上岗

1. 找到产物：`dist\护眼助手-win32-x64\护眼助手.exe`（整个文件夹可复制到任意位置，便携）
2. 双击运行 → 右下角托盘区出现深海蓝鲸尾图标
3. 建议：右键 exe → 发送到桌面快捷方式；打开设置面板勾选「开机自启动」
4. 之后每天开机，他自己到岗（驻留托盘，如勾选自启则静默启动）

## 二、一天的时间线（两种玩法）

### 玩法 A：手动切档（托盘/面板点一下）

| 时段 | 建议模式 | 说明 |
|---|---|---|
| 早上困倦 | 「冷白提神 8000K」 | 冷色提高警觉（白天短时用） |
| 早上开工 | 「办公 5500K」 | 轻度柔和；白天保留节律信号 |
| 下午转晚 | 「傍晚 4500K」 | 昼→夜过渡 |
| 晚饭后 | 「夜晚 3400K」 | f.lux 默认日落暖度 |
| 睡前 1–2 小时 | 「深夜 2700K」 | 降低蓝光剂量（本机实际约 3300K，界面会如实显示） |

### 玩法 B：交给时间调度（v2 新功能，推荐）

设置面板 → 时间调度 → 勾选「启用」。默认带三条：

```
09:00 → 办公（自动）    18:00 → 傍晚（询问）    22:00 → 夜晚（自动）
```

- **自动**：到点静默切换，托盘气泡轻提示
- **询问**：弹一张小卡片「现在是 18:00 — 切换到傍晚吗？」[切换] [忽略] [今天不再问]
- 点「今天不再问」后，该条目当天不再打扰；次日恢复
- 条目可增删改（时间 / 模式 / 自动或询问），每条可单独停用

**两个随时可用的动作**：
- 微调色温：`Ctrl+Alt+↑` 变冷 / `Ctrl+Alt+↓` 变暖（每次 200K）
- 需要看真实颜色（修图、选图）：托盘 →「恢复原色」；看完 →「重新启用护眼色彩」

## 三、感光监测（v2 新功能，默认关闭）

光线暗了自动提醒或切换，不用自己盯时间：

- 设置面板 → 感光监测 → 勾选「启用」
- 原理：优先用**环境光传感器**（有 ALS 硬件的机器免摄像头，状态行显示来源）；
  无硬件的机器自动回退**摄像头**：每 60 秒短暂工作约 1 秒（指示灯闪一下），在**本机**计算环境亮度；
  亮度相对基线骤降 35%（可调）时触发
- 触发行为二选一：**弹卡询问**（默认）或**自动切换**到指定模式（默认「夜晚」）
- **隐私说明：画面仅用于计算一个亮度数值，不保存、不传输。** 任何时间都可关闭
- 高级设置（间隔 / 阈值 / 行为 / 目标模式）在面板「高级设置」折叠区

> 计时说明：为防闪烁误报，需连续几个采样确认变暗后才触发（约 3–5 分钟）；
> 开灯恢复同理。这是有意的防抖设计。

## 四、休息提醒（默认 20-20-20）

- 默认每 **20 分钟**弹一张温和小卡片（**不抢键盘焦点**，正在打字不会被打断）
- 卡片三个选择：**开始休息**（20 秒倒计时）／**推迟 5 分钟**／**跳过**
- 开会、演示、赶工时：托盘 →「暂停提醒 1 小时」（到点自动恢复），或面板「暂停提醒」按钮
- 觉得 20 分钟太频繁：设置面板 → 休息提醒 → 改「工作 / 休息」时长（如 40 分钟 / 5 分钟）

## 五、界面主题（v2）

设置面板 → 通用 → 界面主题：

- **深海**（默认）：DeepSeek 风格深海蓝 + 鲸尾品牌元素
- **暖橙**：经典暖光配色
- **二次元**：蓝发鲸娘配色 —— 星夜靛蓝底 + 星点背景 + 糖果胶囊按钮

主题即时切换，选择记入设置；休息卡片、建议卡片同步跟随。

## 七、关闭与退出

| 操作 | 行为 |
|---|---|
| 点设置窗口的 × | 隐藏到托盘（他继续工作，色彩保持） |
| 托盘 → 退出 | 真正退出；**退出时自动恢复屏幕原色** |
| 崩溃 / 断电 | 下次启动自动检测并先修复屏幕（不会留下偏色） |
| 再双击 exe | 不会开第二个，只会把已有窗口唤到前台 |

## 八、设置套路（打开设置面板一览）

- **场景模式**：7 档一键应用（色温 + 亮度组合）；手动拖滑块后进入「微调」状态
- **色温**：滑块 2000–10000K（暖 → 冷全线）；冷色档（>6500K）红绿衰减、蓝保持
- **亮度**：与室内环境光匹配——诀窍：**拿一张白纸放在屏幕旁，调到屏幕白与纸的观感接近**（办公室约相当于 120nits，暗房间还要更低）
- **休息提醒**：20/20 为 AAO 标准；也可自定义节奏
- **时间调度**：见「二、玩法 B」
- **感光监测**：见「三」
- **通用**：主题切换、开机自启动、热键说明

参数依据（f.lux / AAO / 昼夜节律研究）：`docs/eye-parameters-research.md`

## 九、常见疑问

**Q：他怎么知道现在该用什么色温？**
A：两条路——① 时间调度（推荐）：你在面板里排好时间线，他自动/询问切换；② 感光监测：光线变暗自动建议。

**Q：屏幕看起来没变化？**
A：① 该档位与本机钳制值接近时变化很小（如深夜档）；② 检查托盘菜单是否停在「原色 6500K」。

**Q：色温拖到很低没反应？**
A：显卡驱动限制（50% 规则），最低约 3300K；界面会提示"受显卡限制"。

**Q：冷色档（8000K+）有什么用？**
A：白天困倦时短时提神（冷光提高警觉）；晚间不建议用。

**Q：摄像头测光会不会窃取画面？**
A：不会。测光逻辑在本地完成，只产生一个亮度数值（如 92.4）；数值不落盘、不出机器。代码在 `src\renderer\camera.js`，可自行审阅。

**Q：换电脑用？**
A：把 `dist\护眼助手-win32-x64\` 整个文件夹拷过去双击即可（win10/11 x64）；每台机器的可用色温范围可能不同（自动适配钳制）。
